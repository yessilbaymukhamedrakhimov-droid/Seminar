# Презентация ChatGPT Edu для колледжей

Интерактивная презентация на русском и казахском языках: 13 слайдов, каталог плагинов, Pedagog BilimAI College и Tarbie BilimAI College, пример «Инспектор здания» и пример «3D-обзор компьютерного кабинета».

На слайде 12 — интерактивный компьютерный кабинет, встроенный HTML-пример скилла «3D-обзор» Pedagog BilimAI College. Один промпт с фотографией задаёт реконструкцию помещения, вращение, масштаб, вид сверху, ракурс фото и автообзор. Пример работает прямо в слайде и открывается отдельно. Игра со слайда удалена.

## Запуск

Скачайте репозиторий и запустите локальный сервер в его папке:

```sh
python -m http.server 8765 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8765/#ru/1 — русский язык; #kz/1 — казахский.

Для полного отображения сохраняйте структуру папок и все материалы рядом с index.html. Некоторые внешние демонстрации требуют интернета.

Оба плагина работают в тестовом режиме. Репозиторий: https://github.com/yessilbaymukhamedrakhimov-droid/Seminar. Редакция от 18 ноября 2026 года.


## Проверка локальной версии

Исправлена сборка одного HTML: удалён внешний base URL, который ломал историю и прерывал обработку переключений. Четыре встроенных HTML-примера включены в файл. В мини-презентации кнопки 01–03 переключают слайды, сохраняется выбранный язык.

В актуальном едином HTML изображения, короткие видео и примеры Astra встроены и доступны офлайн. 3D-примерам нужен браузер с WebGL; внешние сервисы могут требовать входа.


## Региональная статистика

Текущая версия содержит только сводные показатели по областям, районам и колледжам. ФИО и персональные записи преподавателей исключены из regional-data.js, интерфейса и актуальных офлайн-архивов. Поиск работает только по районам и колледжам. Итоги исходной выгрузки сохранены.

Актуальный единый офлайн-файл: скачайте Seminar-20-11-2026-statistics-only.zip и откройте HTML из архива. Изображения и встроенные 3D-примеры находятся внутри HTML; внешние сайты требуют интернет.
