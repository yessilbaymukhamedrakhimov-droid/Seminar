# Семинар · ChatGPT Edu · Bilim AI

Интерактивная презентация для педагогов колледжей на казахском и русском языках.

Откройте `index.html` или сайт GitHub Pages.


## Последние правки

Знакомство, идеи и обратная связь открываются кнопками в новой вкладке, без QR.
Задачи по расписанию находятся во вкладке между Chat / Work / Codex и выбором мощности.
PR-надпись размещена рядом с афишей, под приглашением заявить о себе.
Под видео Jeremy Utley добавлены информация о полной версии на YouTube и её название.
