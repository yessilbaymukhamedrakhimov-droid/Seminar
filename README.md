# Презентация ChatGPT Edu для колледжей

Интерактивная презентация на русском и казахском языках. Текущая редакция содержит 12 слайдов, описание Pedagog BilimAI College (10 навыков) и Tarbie BilimAI College (4 навыка), SVG-инструкцию по поиску плагинов, интерактивный пример «Инспектор здания» и индивидуальный практикум «Эвакуация — педагог с группой». Практикум на русском: пять связанных решений, интерактивный план эвакуации, учёт группы и личный разбор.

Индивидуальный практикум опубликован: https://neighbour-dialogue-practicum.chatgpt-edu-3017.chatgpt.site . Слайд 11 содержит QR-код и вход в кабинет ведущего. Участники входят без регистрации, ведущий — через ChatGPT. Результаты разделены по занятиям и доступны владельцу занятия.

## Запуск

Скачайте репозиторий и запустите локальный сервер в его папке:

```sh
python -m http.server 8765 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8765/#ru/1 — русский язык; #kz/1 — казахский.

Для полного отображения сохраняйте структуру папок и все материалы рядом с index.html. Некоторые внешние демонстрации требуют интернета.

Оба плагина работают в тестовом режиме. Исходная презентация: https://github.com/yessilbaymukhamedrakhimov-droid/Seminar. В этой копии сохранены правки от 16 ноября 2026 года.
