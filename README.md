# Презентация ChatGPT Edu для колледжей

Интерактивная презентация на русском и казахском языках: 13 слайдов, каталог плагинов, Pedagog BilimAI College и Tarbie BilimAI College, пример «Инспектор здания» и практикум «Эвакуация при ЧС».

Ситуационный симулятор опубликован отдельно: https://neighbour-dialogue-practicum.chatgpt-edu-3017.chatgpt.site . На слайде 12 — шаги для участников и раскрывающаяся инструкция для ведущего со ссылкой в кабинет. Участники входят по коду и имени без регистрации; ведущий запускает общий таймер на 3 минуты. Каждый управляет своей группой из 20 студентов, видит последствия решений и итоговый разбор. Создание своих сценариев предлагается после семинара.

## Запуск

Скачайте репозиторий и запустите локальный сервер в его папке:

```sh
python -m http.server 8765 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8765/#ru/1 — русский язык; #kz/1 — казахский.

Для полного отображения сохраняйте структуру папок и все материалы рядом с index.html. Некоторые внешние демонстрации требуют интернета.

Оба плагина работают в тестовом режиме. Репозиторий: https://github.com/yessilbaymukhamedrakhimov-droid/Seminar. Редакция от 17 ноября 2026 года.
